# R6 공식 A321 기준 대조 (Airbus 일반 제원 도면 vs R3 · R5-C)

작성: worker sonnet-r6-ref (Claude Sonnet, 일반 속도). 커밋하지 않았다. 이 문서는 연구용 대조 기록이며 OEM 공학 허용오차나 검증 주장이 아니다.

## 결론

1. **R3와 R5-C의 주요 치수는 공식 도면의 인쇄 치수와 일치한다. 그러나 이 일치는 구성상 당연하다.** 길이 44.51 m, 반스팬 16.29 m, 수평미익 반스팬 6.225 m, 동체 폭 3.95 m·높이 4.14 m, 수직미익 5.87 m는 R3 원장(`station_last`)이 곧 도면의 인쇄 숫자다. 독립 검증으로 세지 않는다. R5-C는 R3와 같은 형상이다(모든 비교 행에서 델타 차이 0.0000 m).
2. **공식 도면과 R3의 가장 큰 차이는 새클릿 부재다.** 반스팬 17.90 m 대 16.29 m(편측 −1.61 m, 전체 스팬 35.80 m 대 32.58 m). 엔진·파일런·기어·플랩트랙 페어링도 없다.
3. **16.29 m는 새클릿을 뺀 값이다(인쇄 숫자 세트가 닫힘).** 다만 도면의 날개 끝 그림은 축척이 맞지 않고 약 0.5 m 어긋난다. 아래 §2 참조. "축척으로 확인됨"이라고 쓰지 않는다.
4. 도면 자체의 인쇄 치수 대 그림 길이 비율이 0.79–1.08로 흩어진다. 그림에서 읽은 행(drawn)에 ±0.1 m 대역을 엄격히 적용하는 것은 기준 자체보다 촘촘하다. 대역 판정은 인쇄 행(printed)에만 쓴다.

```text
검증 상태 (R3 = R5-C)
  인쇄 행 12개 : 11 대역 이내 / 1 대역 밖 (half_span_incl_sharklet -1.610)
  그림 행 15개 : 판정 없음(정보용). 최대 |델타| 1.05 deg(HT 후퇴각), 0.155 m(길이/높이)
  입력 STL 6개 : 전후 SHA-256 동일
```

## 1. 입력과 축척

- 원본: Airbus "A321 Aircraft Characteristics - Airport and Maintenance Planning" Jul 01/26, A321neo-ACF/XLR, 471쪽. SHA-256 `50ae7a11b9834cbb1b0f8b862fcb6e85aa7817e77596cd12903033e81456d40d` 일치 확인. 파일은 `Aircraft-Workbench/.migration/bridge/blobs/<sha>`에서 찾았다. 저장소에는 PDF도 쪽 렌더도 넣지 않았다.
- 73쪽: 측면도와 정면도. 74쪽: 평면도. **44.51 m는 74쪽에 있고 35.80 m는 73쪽(정면도)에 있다.** 73쪽에 둘 다 있다는 지시서의 전제와 다르다. 94쪽은 슬랫 지상 간극 표라 윤곽이 없어 쓰지 않았다.
- 도면 두 장 모두 "RELATED TO AIRCRAFT ATTITUDE AND WEIGHT" 주석이 있다.
- 두 쪽은 벡터 도형이라 화살촉 끝과 외곽선 좌표를 직접 읽었고, 400 dpi 렌더에서 화소로 교차 확인했다.

## 2. 16.29 m와 새클릿: 측정 증거

`reference-dimensions.json`의 `sharklet_16_29_evidence`에 값이 있다.

1. **합이 닫힌다(인쇄값).** 16.29 + 1.61 = 17.90 = 35.80 / 2.
2. **16.29 치수선의 끝은 날개 끝의 가로선 위에 있다.** 이 선(74쪽 y=502.03 pt)의 양 끝은 외곽선의 앞전·뒷전과 0.1–1.1 mm 이내로 겹친다(앞전 −0.0001 m, 뒷전 −0.0011 m). 1.61 m 치수는 같은 선에서 시작해 외곽 최대 폭(512.10 pt = 외곽 최대 512.12 pt)에서 끝난다.
3. **날개 끝 시위 1.64 m의 확장선이 이 선의 양 끝과 일치한다**(x=333.04, 345.32 pt). 따라서 1.64 m는 새클릿 연결부의 날개 시위다. 3.22 m는 연결부 앞전부터 새클릿 뒤끝까지의 x 거리다(3.22의 쌍 아님).
4. **인쇄 숫자 세트가 y=16.29에서 닫힌다.** 평면도 외곽의 앞전·뒷전 직선(y 8.6–17.4 구간 적합)을 y=16.29에서 평가하면 시위 1.644 m(인쇄 1.64), 앞전 x=24.499 m(인쇄 27.72 − 3.22 = 24.50)다. 도면의 가로선 위치(y=16.78 m)에서는 시위 1.543 m, 앞전 24.749 m로 맞지 않는다.
5. **그림은 축척이 맞지 않는다.** 가로선은 균일 축척 y=16.78 m(인쇄 16.29보다 0.49 m 바깥)에 그려져 있고, 새클릿은 1.27 m로 그려져 있다(인쇄 1.61). 외곽 반스팬은 18.04 m(인쇄 17.90, +0.8 %). 날개 끝 그림은 인쇄 숫자 세트와 약 0.5 m 어긋난다. 인쇄 숫자 세트가 스스로 닫히므로 인쇄값을 우선하는 것이 일관되지만, 이 도면 하나만으로 그림 쪽 오차의 원인을 확정하지는 못한다.

신뢰도: "16.29는 새클릿을 뺀 연결부 반스팬이다" 높음(인쇄 숫자 닫힘 + 치수선 끝 위치). "그림 위치가 곧 16.29다" 틀림(0.49 m 차이).

## 5. R6가 고쳐야 할 발견

- 새클릿의 포함 또는 명시적 제외 결정. 제외하면 스팬 32.58 m 모델이라고 명시하고 공력 비교에 반영한다. 포함하려면 이 도면(날개 끝 약 0.5 m 부정확)이 아닌 다른 근거가 필요하다.
- 엔진·파일런·기어·플랩트랙 페어링의 포함 여부 결정(공력 비교 목적에 따라).
- R3의 기존 HOLD 항목(날개 뿌리와 장치 이음새의 보간/외삽)은 이 대조로 해소되지 않는다. 날개 뿌리 시위 차이는 +0.029 m지만 뿌리 형상 자체는 검증하지 않았다.
- 기준면(자세) 결정: 배면 높이 1.95 m의 출처와 도면 1.80 m의 차이를 정리한다.
- 그림 행의 델타 0.25 m 이하는 고칠 대상이 아니다(도면 축척 한계 안).

## 6. 산출물과 명령

위치: `research/a321-quality/r6/reference/` (기존 파일은 수정하지 않았다).

| 파일 | 내용 |
|---|---|
| `extract_drawing_dims.py` | 도면 치수 추출(벡터 + 화소 교차 확인), 27개 치수와 평면·측면·정면 키 점 |
| `reference-dimensions.json` | 치수 목록(라벨, 값, 쪽, 읽은 의미, 신뢰도, 그림 길이, 암시 축척, 비율), 축척, 키 점, 16.29 증거 |
| `measure_models.py`, `model-measurements.json` | R3·R3 부품·R5-C 측정과 기준 대조, 단면 프로파일 |
| `build_reference_scene.py` | Blender 5.2.2 장면과 오버레이 렌더(GPL-2.0-or-later 분리 어댑터) |
| `make_figures.py`, `figures/*.svg` | 선만 그린 비교 그림 4장. 에어버스 래스터나 외곽선 트레이스 없음 |

PNG 대신 SVG인 이유: 저장소 `.gitignore`가 `*.png`를 무시한다.

실행(작업 디렉터리: 위 경로, `$R`=워크트리 루트, `$S`=세션 scratchpad, 실측 wall time은 `uv` 시작 포함):

```bash
uv run extract_drawing_dims.py --pdf <PDF> --out reference-dimensions.json --render-dir $S/r6-ref-pages      # 4.3 s
uv run measure_models.py --repo $R --reference reference-dimensions.json --out model-measurements.json      # 12.5 s
uv run make_figures.py --reference reference-dimensions.json --models model-measurements.json --out-dir figures   # 6.7 s
blender.exe -b --factory-startup --python build_reference_scene.py --python-exit-code 1 -- \
  --repo $R --pages-dir $S/r6-ref-pages --reference reference-dimensions.json --out-dir $S/r6-ref-blender   # 12.2 s
```

Blender는 Cycles CPU 16 샘플, 방출 재질만 사용했다(GPU·조명 없음). 오버레이 6장(상·측·정면 × R3·R5-C, 1600 px 너비)과 `.blend`는 scratchpad(`$S/r6-ref-blender/`)에 있고 저장소에는 없다. 에어버스 쪽 렌더(400 dpi)는 `$S/r6-ref-pages/`에만 있다.

입력 STL 6개의 SHA-256은 전후 동일(R3 `2c0111c3...e745`, R5-C `5466466c...d7b`, 부품 4개 포함 `diff` 일치). `model-measurements.json`에도 전후 값을 기록했다.
