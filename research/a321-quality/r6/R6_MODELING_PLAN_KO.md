# R6 공력용 모델링 계획 (Blender · 부품별 닫힌 곡면 · 반쪽 영역)

**결론: R6는 Blender를 스크립트 기반 모델링·조립·검사 환경으로 쓰고, 부울 합치기 없이 부품별 닫힌 곡면 4개를 만든다. 반쪽 모델은 격자 단계에서 y=0 대칭면으로 자른다.** 이 문서와 [계약 02](plans/r6-geometry-contract-02.json)는 R6 후보를 만들기 전에 커밋한다(2026-11-16). R5-C는 자기 계약 기준으로 M3 FAIL을 유지한다.

## 1. 왜 이렇게 바꾸나

| R5까지 관찰된 문제 | 원인으로 보는 것 | R6에서 바꾸는 것 |
|---|---|---|
| 단면마다 기울기 꺾임 | 단면 사이 직선 연결 | 단면을 지나는 C2(필요하면 C1 형상보존) 곡선 보간 |
| 주익 뿌리의 길고 가는 삼각형, 최소 품질 9.7e-13 | 부울 합치기 뒤 허용오차 정리 | CFD 입력에서 부울 금지, 부품별 닫힌 곡면 |
| 중심선 이음매 위 C15 레코드 | 좌우 반쪽을 붙인 이음매(가설 B) | 동체는 처음부터 한 바퀴 닫힌 링, 날개는 y=0을 가로지르는 한 장의 격자 |
| 정점 부채꼴(가설 C), 공유 대각선(가설 A) | 극점 부채꼴, 대각선 선택 | 정점 차수 ≤ 8, 최소각을 최대로 하는 대각선 |

비유하면 R5까지는 완성된 장난감 비행기를 잘라 붙여 풍동 모형을 만든 것이고, R6는 도면 치수와 단면으로 동체·날개·꼬리를 각각 깎아 끼우는 방식이다.

## 2. 흐름

```text
[R6-0 기준]  공식 도면 치수표 · Blender 기준 장면 · R3/R5-C 대조      sonnet-r6-ref
     │
[R6-1 검사도구] 검사기 2개 + surfaceCheck · 품질 · 매끄러움 · 기준값    sonnet-r6-checks
     │
[계약 02a]   기준값을 보고 Q_MIN·각도·크기비·이면각·꺾임비 수치 고정     Opus (생성 전 커밋)
     │
[R6-2 생성]  Blender bpy: 동체·주익·수평·수직 닫힌 곡면 + 특징선 목록    생성 Worker
     │
[R6-3 검사]  부품별 G1~G7 · 조립 A1~A4 (교선 고리·스침 없음·도면 대조·화면)
     │  FAIL → 원인 기록 → 새 후보 (기준 변경 없음)
     │  PASS
[M3 PASS] → [M4 물리] → [M5 반쪽 영역 격자: y=0 symmetryPlane, 부품별 STL, 교선 특징선]
     │
[비교 V]   OpenVSP 같은 치수 모델 · CompGeom · VSPAERO로 CL/CDi 개략 비교 (설치 승인 후)
```

## 3. 반쪽 모델을 이렇게 하는 이유

- 받음각 0°, 옆미끄럼 0°의 정상 유동은 좌우 대칭이므로 y ≥ 0만 계산하고 y=0에 대칭 경계를 둔다. 셀 수와 계산 시간이 약 절반이 된다.
- 형상은 반으로 자르지 않는다. OpenVSP 개발자 안내도 대칭면과 원거리 경계는 체적 격자기가 만들게 하라고 권한다. 모델에서 자르면 y=0에 열린 면과 이음매가 생겨 R5의 문제가 다시 생긴다.
- snappyHexMesh에서는 domain 경계를 y=0에 두고 `symmetryPlane` patch로 지정한다. 대칭면에서 `mergeAcrossPatches`를 쓰지 않는다(v1906 이슈: 대칭면이 평면이 아니게 됨).
- 한계: 비대칭 와류 흘림처럼 좌우가 달라지는 현상은 잡지 못한다. α=0 부착 유동 첫 시험에서는 문제가 되지 않는다고 본다.

## 4. 부품별 입력을 쓰는 근거

과거 snappy-03은 하나로 합친 `aircraft.stl`을 썼다. R6는 부품 4개를 따로 넣는다. snappyHexMesh는 여러 triSurfaceMesh를 받아 외부 영역을 정하고, 교선은 `surfaceBooleanFeatures`로 특징선을 만들어 붙잡는다(WSL OpenFOAM v1912에 `/usr/bin/surfaceBooleanFeatures` 있음, 2026-11-16 확인). 부품별 patch는 힘을 동체·주익·꼬리로 나눠 볼 때도 필요하다.

## 5. Blender의 역할과 금지

- 쓰는 것: bpy 스크립트로 곡면 격자 생성, 이름·속성 부여, 공식 도면 기준 평면(기준 장면), 정사영 렌더, STL·.blend 저장, 새 프로세스 재열기 검사.
- 쓰지 않는 것: 부울, remesh·decimate, 허용오차 정리, 기록 없는 수작업 편집. R5에서 가는 삼각형이 생긴 경로다.
- Blender 내장 Python에는 scipy가 없다. 곡선 계산은 numpy로 직접 하거나 uv에서 미리 계산해 Blender에서 조립한다.

## 6. 범위에서 뺀 것과 공력 영향

| 뺀 것 | 영향 |
|---|---|
| 샤클렛(가로 1.61 m, 높이 2.43 m) | 같은 CL에서 유도항력이 크게 나오고 날개 끝 하중 분포가 다름 |
| 엔진·파일론 | 날개 아랫면 압력과 간섭 항력이 빠짐 |
| 플랩·슬랫·틈새 | 저속 고양력 효과 없음(깨끗한 날개) |
| 착륙장치·벨리 페어링 | 해당 항력 빠짐 |

현재 R3 원장의 주익 반스팬 16.29 m는 공식 도면에서 샤클렛을 뺀 날개 끝까지의 치수와 같은 값이다. 도면 축척으로 실제로 확인하는 일은 sonnet-r6-ref가 한다.
