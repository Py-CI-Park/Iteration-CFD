# M1 · R5-A 초기 형상 작업 명세

실행 기준 e3b809d. plans/r5-geometry-contract-01.json을 생성 전 고정하고, R3 STL·단면 원장 해시로 입력을 제한한다.

## 첫 R5-A의 범위

동체·주익·수평미익·수직미익의 원 단면 원장을 기반으로 길이/span 방향 곡선과 tessellation을 다시 구성하는 별도 초안이다. 좌우는 명시적으로 미러한다. 원자료의 익형을 OEM 단면이라고 부르지 않는다. 엔진·파일런·기어·장치 틈은 첫 airframe 셸 범위에서 생략하며 실제 항공기 전체 항력을 재현했다고 해석하지 않는다.

기존 station 대응 점과 bounds는 float32 저장까지 고려해 1e-5m 이내를 목표로 유지한다. station 사이 표본 이탈 상한은 동체25mm, 주익10mm, 미익10mm로 두고 전체 체적 변화는 R3 대비1% 이내로 제한한다. 이 값은 초기 파생 형상을 제한하기 위한 연구 가정이며 실기 공학적 허용오차가 아니다.

| 항목 | 명세/검사 |
|---|---|
| 입력 | R3 frozen STL 및 reconstruction-r3.json |
| 생성 | 전체 단면 궤적의 제어 가능한 곡선과 별도 표면 생성 |
| feature | LE/TE·평면형 꺾임은 의도와 변경 여부를 명시. 원점 고정만으로 익형 적합성을 주장하지 않음 |
| 매끄러움 | 조명/shading이 아닌 실제 좌표·기울기/곡률 지표를 비교. chordwise/spanwise·Boolean seam의 범위를 나누어 기록 |
| 형상 편차 | 원 station, between-station 표본, bounds, 체적을 서로 다른 검사로 보고 |
| 위상 | 폐합·방향·정점 link·퇴화/중복면·성분·독립 교차 검사 |
| native | 별도 Blender 저장과 새 프로세스 재읽기, STL·배열 좌표 결합 |
| 원본 | R3/R4 및06~11을 저장/재생성하지 않음 |

## 중단과 진행

```text
입력 해시 → 명세 동결 → 새 후보 생성
                           |
                    허용범위/위상 검사
                      |         |
                    FAIL       PASS
                      |         |
                 실패 보존     독립 교차·native 검사
                 원인 분리            |
                               M3 인수 판정
```

미측정·실패를 PASS로 바꾸지 않는다. 초기 R5-A가 이 기준을 통과하지 못하면 같은 결과의 한계를 기록하고 새 후보로 수정한다. 기준을 사후 완화하지 않는다. 곡선 재구성만으로 날개-동체 전이 패치 설계가 완성됐다고 표시하지 않는다.

M4의 물리적 경계층 높이·총두께·모델 선정과 M6 이후 엔진 인수는 별도 작업이다. 새 외형이 생겨도 기존 GPU 전 체크포인트를 임의로 증가시키지 않는다.

## 방법 보충 01 (A 실행 후·B 실행 전)

실제 A 구현은 원 단면 envelope의 대응 점 궤적을 길이/span 방향 PCHIP으로 재구성하고, 원 꺾은선 위 2%/98% 보조 제어점을 추가했다. 원래 chordwise polygon과 Boolean seam을 유지한다. 따라서 전역 chordwise C1·신규 접합 필렛·의도적 평면형 꺾임의 독립 분류를 완료했다고 주장하지 않는다.

plans/r5-method-supplement-01.json은 이 구현 범위를 규범 문서에 연결한다. A 실행 전에 해당 방법 문서가 동결됐다고 소급하지 않으며, 원 r5-geometry-contract-01.json은 수정하지 않는다. M1은 초기 입력·수치 계약까지이고 전체 feature/전이 설계는 미완료다. B의 cleanup 방법·실행 코드·명령은 실행 전에 별도 고정한다.
