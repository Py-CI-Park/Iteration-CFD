# R7 동체 단계 A: 계약 03a용 측정과 제안 (sonnet-r7-fuselage)

작성: worker sonnet-r7-fuselage (Claude Sonnet, 일반 속도). 커밋하지 않았다. 단계 A만 했다. R7 동체 표면, 배럴 시험, 메셔, 솔버, GPU는 쓰지 않았다. 이 문서는 연구용 측정 기록이며 OEM 공학 허용오차가 아니다. 모든 수치는 `r7-measure.json`에 있다.

## 결론

비유: 도면은 같은 비행기를 위와 옆에서 찍은 두 장의 그림자 사진이다. 두 장이 서로 맞는 정도(좌우 대칭, 척도, 길이)를 먼저 재고, 그 오차를 윤곽 허용 대역으로 삼았다.

1. **추적 성공.** 동체 외곽선은 검은 선 경로(선분과 3차 베지어)에서 읽었다. 평면도는 폐곡선 하나(661점), 측면도는 크라운과 벨리 두 가지다. 숨은선 틈은 크라운 0.60 m(x 26.56–27.16)와 벨리 9.08 m(x 15.70–24.78, 날개·엔진 아래) 두 곳이며 양 끝이 같은 직선 위에 있어 직선으로 이었다. 이것은 가정이다.
2. **R3 상수 단면:** 크라운 z 6.0900, 벨리 z 1.9500, 최대폭 z_w 4.0199, **ρ = 0.49999**(범위 0.49972–0.50028), x 6.217–30.336 m(허용 1 mm, 98개 스테이션). 즉 ρ = 0.5이고 단면은 반축 (1.975, 2.07)의 타원 하나다. 측면 z 오프셋은 **+4.0200 m**(중간 높이를 R3 4.02에 맞춤). 잔차는 크라운 −1.5 mm, 벨리 +2.3 mm.
3. **A5 근입 여유는 모두 충분하다. 정지 사유 없음.** 가장 얇은 곳은 **수직미익 뿌리 후미 끝 (x 42.340, y 0, z 5.500)에서 0.287 m**다. 수평미익 0.452 m (42.209, 0, 4.595), 주익 0.649 m (18.266, 0, 2.601). R3 동체 기준값과 1.4 mm 안에서 같다(0.288/0.451/0.650). 제안 마진 0.075 m의 각각 3.8배, 6.0배, 8.7배.
4. **접합 고리 수는 기대와 같다:** 주익 2, 수평미익 2, 수직미익 1. 최소 면 사이 각은 주익 47.3°, 수평미익 63.1°, 수직미익 22.7°(수직미익 앞전이 크라운과 만나는 점 (35.943, −0.003, 6.131)). 5° 아래 선분 0개.
5. **링 규칙으로 02a 문턱을 서면으로 만족한다.** 268개 링, 링당 128점, 삼각형 약 68,352개. 최소 각 18.3°(눕힌 스트립 11.4°), 종횡비 최대 3.4(눕힌 스트립 7.8), 인접 면적비 최대 1.79, 이면각 최대 7.8°(닫힘 대역 인접 스트립 제외, 포함하면 19.3°).
6. **주의할 도면 사실** (§2, §8): 꼬리 끝은 뾰족하지 않고 폭 0.405 m, 높이 0.391 m의 평평한 끝이다(R3도 0.401 × 0.377). 코 부분은 R3와 다르다(폭 최대 −0.118 m, 코끝 높이 −0.082 m). 풍방 유리 모서리(크라운 x 1.395, 꺾임 23°)는 C2 스플라인으로 못 따라간다. 도면의 "상수 구간"은 완전히 평평하지 않다(폭 5.3 mm, 벨리 3.9 mm 변동).
