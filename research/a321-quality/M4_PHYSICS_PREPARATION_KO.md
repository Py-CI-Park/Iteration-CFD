# M4 · 물리 명세 준비 (미수용)

M2/M3와 독립적으로 정리할 수 있는 입력·판정 항목만 작성한다. 이 문서는 runnable solver case나 물리 인수 통과가 아니다.

| 항목 | 현재 정의/할 일 |
|---|---|
| 목표 | U=(30,0,0)m/s, 모델 기준 받음각0° |
| 물성 | 기존 rho1.225kg/m3, nu1.5e-5m2/s는 준비 가정. 고도/온도·저마하 물성 일관성 확정 필요 |
| 유동 경로 | U/p/T를 푸는 coupled 드라이버 실제 계약 확인. 난류 전용 실행기를 전체 유동 해석으로 쓰지 않음 |
| 난류/벽 | SST 등 지원 경로 검토 후 벽함수/근벽 해상도 방식과 설계 목표를 함께 선정 |
| 경계층 | 첫 높이·총두께·층수·확장비·누락/종료 위치를 함께 설계. 숫자만 키워 격자 검사 통과시키지 않음 |
| 힘 기준 | 기준면적·길이·모멘트점·lift/drag 방향·압력 기준을 고정해야 CL/CD 계산 가능 |
| 진단 | 실제 y+는 계산 후 확인. 사전 추정치를 solved y+로 표시하지 않음 |
| 중단 | NaN/발산·질량 불균형·잘못된 장치·메모리초과 등 조건을 실행 전에 고정 |

기존 wing 단면으로 gross XY 투영 면적과 mean geometric chord를 읽기 전용 계산해 evidence/r5-m4-baseline-area-planning.json에 기록했다. 동체 내부 root를 포함하는 gross 면적이며 wetted area나 MAC가 아니다. R5 형상이 수용된 뒤 최종 기준값을 다시 측정·고정한다.

M6 native 드라이버는 GPU 초기화가 먼저이므로 CPU-only 검사로 실행하지 않는다. 이 제한을 우회하거나 Python 재읽기를 실제 엔진 인수라고 표시하지 않는다.
